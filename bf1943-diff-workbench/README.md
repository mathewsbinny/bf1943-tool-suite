# BF1943 Diff Workbench (bf1943-diff-workbench)

Part of the BF1943 Tool Suite. **BF1943 status: not adapted yet** - copied from OPFOR's BFBC2 suite.

- `level-diff/`: LevelDiff, which compares two BFBC2 binary `.dbx` files instance by instance (see its README).
  It is not tested on BF1943 files; its BFBC2 tests were removed.
- The rest of the workbench is planned in OPFOR's design ([DESIGN.md](../docs/opfor-bfbc2/DESIGN.md)).
